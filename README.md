# Kinetic Low Poly Mechanisms

Six standalone Three.js low-poly mechanism and mathematical motion studies:

- `low-poly-chromatic-clockwork-turbine.html`
- `low-poly-kinetic-gear-bridge.html`
- `low-poly-relativistic-wave-interferometer.html`
- `low-poly-nanomachine-experiment.html`
- `low-poly-planetary-harmonic-transmission.html`
- `hopf-fibration-bloom.html`

Open `index.html` to choose between the demos. Each study is contained in a single HTML file and includes camera controls, cinematic lighting, low-poly geometry, and purposeful animation. The newest Bloom study visualizes sampled Hopf fibers on the 3-sphere, animated by norm-preserving 4D rotations and stereographically projected into 3D.
